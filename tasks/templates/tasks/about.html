What is TaskFlow?

TaskFlow is a simple task management web application built with Django. It helps users organize daily activities, manage responsibilities and keep track of important tasks in one place.

What Does It Do?

Users can create new tasks, view task details, edit existing tasks and delete tasks with a confirmation step. Each task includes a title, description, status, due date and creation time.

Tasks can be tracked through three statuses: Pending, In Progress and Completed.

Key Features

  • Create and manage tasks.
  • View complete task details.
  • Edit task information and status.
  • Delete tasks after confirmation.
  • Set due dates and track progress.
  • Switch between Dark Mode and Light Mode.

Technologies Used

Python · Django · SQLite · HTML · CSS
